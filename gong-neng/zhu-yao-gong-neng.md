# 首页与启动配置

## 游戏目录与资源状态

左侧显示当前游戏目录、MOD 开关和完整包状态。点击目录选择按钮可更换魔兽安装位置。

“完整包已安装”和“MOD 已开启”表示不同状态：前者说明客户端检测到完整资源；后者决定资源是否在所选分支中生效。

- **开启/关闭 MOD**：控制所选分支的 MOD。没有完整包也能开启基础功能。
- **安装完整包**：选择本地完整 ZIP、A/B 包或资源文件夹。
- **重新安装完整包**：新版客户端在已安装时显示此文案；需要你重新选择安装源。
- **下载入口**：进入资源获取页面，不会把客户端源码当作资源包安装。

## Retail 与 PTR

Retail 使用 `_retail_`，PTR 使用 `_ptr_`。只有游戏已安装对应分支时才能选择。

当前客户端的分支切换会把淬火资源移到所选分支，减少两份 MOD 占用的空间。游戏本体的 `x86_64`、`Data` 等内容不属于这次 MOD 移动。

切换前退出游戏。如果你曾在两个分支分别手动安装不同 MOD 或自定义资源，请先备份；不要把分支切换当作合并两套自定义内容的工具。

## 魔兽版本

通常选择“自动检测”。需要兼容旧游戏构建时，可手动选择 1.36 及以下、2.0–2.02、2.03–2.04 或 3.0 及以上。

手动选择会决定资源配置，请与实际游戏版本对应。安装淬火不会升级魔兽本体。

## 画质模式

| 选择 | 对应资源 | 说明 |
| --- | --- | --- |
| SD 经典 | 经典画质对应的资源与皮肤 | 多项高清画面调整不可用 |
| HD 高清 | 淬火高清资源 | 可选择多种地形、树木和光照 |
| DE 决定版 | 3.0 决定版对应的资源 | 只允许原版与淬火决定版地形，水面不可单独调整 |

DE 要求对应的 3.0 及以上游戏配置。经典画质 SD 与 HD 下的怀旧模式不是同一个选择；怀旧模式只适用于 HD。

从 HD 切到 DE 时，如果原来选择原版地形，客户端保留原版；如果选择其他 MOD 地形，新版客户端会改成淬火决定版并应用资源。切回 HD 后可重新选择 HD 地形。

## 更新与启动

首页可以检查 MOD 和完整包更新。更新完成或安装完成后，新版客户端会按你的保存配置应用资源；如果提示设置应用失败，先处理详情再测试画面。

确认 MOD 开关、分支、版本和画质后，点击“启动游戏”。需要启动地图或战役时，使用上方“战役”入口。
