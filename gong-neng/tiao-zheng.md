# 界面与基础设置

## 游戏 UI

在“设置 → 游戏设置”选择经典、淬火或暴雪 UI 风格。客户端根据游戏版本应用对应的游戏 UI 资源。

游戏 UI 风格与客户端窗口主题是两项不同设置。客户端主题入口位于顶部“主题”。

旧 WPF 客户端的镜头、迷雾、改键页面截图不能作为新版本的按钮说明。需要改键时，请以你所用游戏或平台实际提供的选项为准。

## 渲染兼容选项

在“设置 → 基础”中，Intel/AMD 着色器兼容选项可用于排查相应渲染问题。是否需要开启取决于显卡、驱动和游戏版本，不要只凭品牌判断全部机型都需要它。

画面设置还提供物体着色器、后处理和辉光开关。排查时每次改变一项并重启游戏，方便确认影响。

## 重置渲染组件

“设置 → 基础 → 重置渲染组件”用于重新部署客户端管理的核心渲染资源。操作前退出游戏，并备份你手动修改的同名文件。

重置渲染不能补齐没下载的 A/B 包，也不能替代选择正确的游戏分支与画质。

## 关闭与删除 MOD

首页“关闭 MOD”会停用当前分支的资源，并将客户端管理的内容停放在 `QMoff`。需要再次使用时，可以开启 MOD。

“基础”中的删除 MOD 是另一个操作。只想暂时使用原版时，选择关闭即可；使用删除功能前先备份自定义资源，并阅读客户端的确认提示。
