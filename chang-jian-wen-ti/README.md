# 常见问题

- 资源包安装失败、完整包状态不对、空间不足：读[安装与资源包](an-zhuang-yu-zi-yuan.md)。
- 游戏打不开、白屏、地形或皮肤错位：读[游戏画面与启动](you-xi-cuo-wu.md)。
- 不清楚按钮用途或为何置灰：读[功能](../gong-neng/README.md)。

## 反馈时需要的信息

请提供客户端版本与下载来源、游戏版本、操作系统、显卡、Retail/PTR、SD/HD/DE、当前 MOD 开关，以及完整错误信息。

安装问题还需要所选 ZIP/文件夹名称、A/B 是否齐全、目标路径和目标磁盘剩余空间。画面问题需要地图名称、所选地形、光照与水面模式。

你若使用测试客户端，请写明测试包名称。不要只发进度数字或裁掉错误详情。
