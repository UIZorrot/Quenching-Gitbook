# 客户端与资源包更新

## 三种下载文件

| 文件 | 用途 | 玩家操作 |
| --- | --- | --- |
| Windows/Mac 客户端 ZIP | 客户端程序与内置资源 | 解压运行，保留整个目录 |
| 完整 MOD ZIP 或 A/B ZIP | 模型、地形等完整资源 | 使用完整包安装入口 |
| 自动更新的 .bin、.zst 等产物 | 客户端读取的更新数据 | 无需手动下载或解压 |

源码 ZIP 也不能代替便携客户端或完整包。

## 自动检查与确认

新版客户端在启动后的后台检查客户端和 MOD 资源更新。网络不可用或检查失败时，你仍可使用已有客户端；“检查失败”不代表已安装资源遭到删除。

发现更新后，先阅读当前版本、目标版本和更新提示。客户端在你确认后才下载并安装。客户端与 MOD 同时需要更新时，新版流程先处理 MOD 资源，再处理客户端。

首页也提供“检查 MOD 更新”和“检查完整版更新”。完整包缺失、版本无法识别或无法使用资源更新时，客户端会引导你获取完整包；这个提示不表示已帮你下载完整 ZIP。

MOD 安装或资源更新完成后，新版客户端按保存的配置重新应用资源。若提示部分设置失败，请处理错误详情，不能把复制完成当作配置已全部生效。

## Windows 客户端

Windows 客户端在支持的旧版本上提供自动更新。升级后需要重启，设置会继续使用原来的配置位置。

如果旧构建出现基线不匹配，或自动更新没有可用方案，请从[客户端 Release](https://github.com/UIZorrot/Quenching-Client/releases/tag/3.5)下载完整便携 ZIP，解压到新目录运行。不要强行应用别的构建的差分文件。

保留旧客户端目录供回退。替换客户端不是把完整包重新安装到游戏目录，也不要求你删除已有自定义资源。

## Mac 客户端

Mac 当前通过手动替换 `QMClient.app` 更新。下载与你处理器架构相符的包，保留旧版；不要等待 Windows 自更新助手执行。

## 版本说明

淬火对外版本 **3.5**、客户端内部构建版本和魔兽游戏版本是三项不同的信息。当前公开 3.5 客户端 Release 的内部版本为 `3.5.1`；首页“3.0 及以上”指魔兽版本范围。

本手册同时补充近期 3.5 测试客户端的流程：直接选择 ZIP/文件夹、已安装时显示重新安装、安装后应用配置，以及地形/悬崖/透明水资源对齐。它们不表示 2026 年 10 月 8 日的本地测试包已经替换了公开 Release。请以你下载的包和发布说明为准。

玩家无需根据本文下载测试构建的内部更新产物，也无需手动编辑资源版本标记。
